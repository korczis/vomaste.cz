{#- Central JSON-LD (structured data), rendered exactly once per page from base.html — the same "declared once" discipline as the meta tags. Everything is generated from front matter, config.toml, data/navigation.toml and data/dossiers.toml; no dossier slug, person name, or URL is hardcoded here, so this file needs no change when a dossier is added or records move between dossiers. Editorial constraint (AGENTS.md rules 3 & 7): claim statuses on this site describe SOURCING, not adjudicated truth. Therefore no ClaimReview and no reviewRating anywhere — claims are neutral schema.org Claim nodes whose `appearance` points at the cited reporting. scripts/dossier/verify-jsonld.mjs enforces this mechanically after every build. Cross-references are resolved layout-agnostically: - the Person entry comes from data/dossiers.toml, matched by the page's own extra.dossier slug (dossier_type = "entity" only — the aggregate view is not a person and never gets Person markup); - a claim's cited sources are found by walking every dossier section under content/dossiers/ and matching extra.src_id, so records may physically live under any dossier; - breadcrumbs come from the page's/section's own `ancestors` chain. -#} {%- import "macros/jsonld.html" as jsonld -%} {%- set ld_lang = page.extra.lang | default(value=section.extra.lang default(value=section.description | default(value=config.description)) -%} {%- set ld_seo_type = page.extra.seo_type | default(value=section.extra.seo_type | default(value=config.extra.seo_type | default(value="WebPage"))) -%} {%- set ld_record_type = page.extra.record_type | default(value=section.extra.record_type | default(value="")) -%} {%- set ld_dossier = page.extra.dossier |
