Patička je parametrem uzavíracího makra, protože dvě nezávislá Tera makra nesdílejí stav a patička patří až za tbody. Propojení s JSON-LD: obal nese data-record-type (např. "claim", "source", "relation") — deklaruje, že řádky tabulky odpovídají JSON-LD uzlům téhož typu, které stránka už vydává (viz templates/partials/jsonld.html a scripts/dossier/verify-jsonld.mjs; hodnoty odpovídají record_type ve front matter). Data pro tabulky dnes pocházejí ze stejných front-matter/data zdrojů jako JSON-LD @graph — tabulka i strukturovaná data jsou dvě reprezentace téhož záznamu, nikdy dvě ručně udržované kopie. Plánovaný budoucí zdroj je DuckDB (.mjs) pipeline nad stejnými záznamy; je to PLÁN, nikoli existující schopnost — neimplementováno, nic v UI ani dokumentaci nesmí tvrdit opak (konstituce §8). Sentinel je řetězec, ne -1: Tera 0.22 neumí záporné číslo jako výchozí hodnotu parametru makra ("expected an integer, a float, a string, or `true`/ `false`" — unární minus tam není literál). searchable — true přidá vyhledávací pole napojené na Alpine komponentu advancedTable (assets/js/modules/ table-filter.js, stejný vzor jako claims-filter.js); false = žádný JS extra_class — volitelné další utility třídy obalu (např. "" (výchozí) = žádné řazení, stejný sentinel jako u columns/count. facets — pole dvojic "hodnota::popisek" pro filtrovací čipy nad tabulkou; řádek se pozná podle data-facet. Klíč se objevuje i v URL (?type=…). "" (výchozí) = bez selectů. url_state — true promítne hledání/řazení/faset do query stringu, aby šel výřez dat poslat odkazem (§ 8 mise).
